# Предлагаемые схемы 2.0 Survival

Это результат этапа 1 нового ТЗ с животными. **Файлы не загружаются текущей игрой.** Действующий баланс персонажа находится на уровень выше: `assets/data/survival.ron`.

| Пример | Будущий контракт |
|---|---|
| `blocks.ron` | Блок: строковый ID, грани, твёрдость, инструмент/tier, дроп и XP; показаны stone и новая шерсть |
| `items.ron` | Предмет: строковый ID, стек, вид; все предметные ссылки остальных примеров объявлены здесь |
| `ores.ron` | Рудный блок: высоты, жилы, допустимые основы и слой оверлея |
| `recipes.ron` | Рецепт: вид, входы, результат; у Smelting дополнительно seconds/XP |
| `tools.ron` | Характеристики деревянной кирки; общая таблица материалов из ТЗ |
| `animals/cow.ron` | Вид животного: HP, скорость, размер, модель, веса биомов, дроп и XP |
| `animals/rules.ron` | Первичный/дополнительный спавн, A*, Wander/Panic, шерсть и яйца |
| `food.ron` | Восемь видов мяса: абсолютные прибавки hunger/saturation, время 1.6 с |
| `combat.ron` | Дальность/cooldown, урон, износ, отбрасывание и время эффекта/смерти |
| `models/cow.ron` | Отдельная модель из шести частей и декларация TODO(art)-текстуры |

ID разрешаются в общем снимке каталога. Базовые блоки Foundation берутся из явной таблицы в [плане](../../../docs/SURVIVAL_V2_PLAN.md); `blocks.ron` переопределяет stone и добавляет wool, `ores.ron` объявляет coal_ore, `models/cow.ron` объявляет cow_model. Пространства блоков/предметов/моделей различаются: совпадающий строковый ID блока и его предмета допустим. Повтор ID внутри одного реестра, неизвестная ссылка, неверный диапазон или смешение типов отклоняет весь новый снимок, сохраняя предыдущий. `kind: Food` требует соответствующей записи в `food.ron`.

Модель: размеры в блоках, pivot — центр части относительно ног; Leg вращается вокруг верхней грани части. UV — шесть прямоугольников `(x,y,width,height)` в пикселях текстуры, порядок +Y/−Y/−X/+X/+Z/−Z. Все прямоугольники должны помещаться в texture.size. Placeholder объявляет будущую заглушку в отдельном атласе существ; PNG сейчас не создаётся и исходные 17 текстур не меняются. Остальные три вида и их модели добавляются при реализации этапа 6 по таблице ТЗ.

Новые допущения отмечены в RON и плане: нулевые веса гор/океана, начальный шанс группы 0.10, A* максимум 256 узлов, Flutter 1.5 блока/с, износ ножниц 1, заморозка dormant-таймеров и твёрдость шерсти 0.8. Это предлагаемые значения для дальнейшей реализации, а не уже согласованные дополнительные требования.

На этапе 3 загрузчик проверяет полную типизированную схему и ссылки. До этого проверка RON означает только синтаксис; она не доказывает наличие в игре руд, животных или еды. Каталоги животных в рабочем наборе будут в `assets/data/animals/`, модели — в `assets/data/models/`; `examples/` останется документацией и не должен случайно загружаться рекурсивным поиском рабочего контента.
