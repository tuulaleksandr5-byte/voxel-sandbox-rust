# Application icon

The application icon was prepared from the inline logo reference using the image editing tool. The original logo PNG bytes were not included in `textures_cut.zip`; this is a prepared icon rendition of that reference, not a byte-for-byte copy of an uploaded logo file.

`app.png` is the prepared square source; `app-128.png` is the native window/taskbar icon. `app.ico` contains16,24,32,48,64,128,256px Windows resources. The ICO is embedded in the Windows EXE via windres (GNU) or Windows SDK rc.exe (MSVC). All original block texture PNG files are separate and unchanged.
