# Исходные изображения инструментов

Все 77 PNG получены из пользовательского `tools.zip` и сохранены побайтно, без обрезки, поворота, перерисовки или пересжатия. Контрольные суммы архива и каждого файла — в `source-hashes.json`.

- `128x128/`, `64x64/`, `32x32/` — по 25 прозрачных значков: кирка, меч, мотыга, топор, лопата × дерево, камень, железо, золото, алмаз.
- `tools_atlas_128x128.png` — исходный атлас 640×640, сетка 5×5.
- `tools_sheet.png` — исходная непрозрачная таблица с названиями; это референс, не значки игры.

Клиент использует отдельные PNG 128×128 с линейной фильтрацией и исходным RGBA. Каждый значок декодируется и кешируется один раз. Весь набор 128×128 встроен в EXE; при запуске файл `assets/textures/tools/128x128/<имя>.png` рядом с EXE или в текущем каталоге имеет приоритет. Неверный размер/повреждение внешнего файла дают warning и возврат к встроенному оригиналу. После замены внешнего файла нужно перезапустить игру.

Привязка — `survival:<имя файла без .png>`, например `survival:wooden_pickaxe` или `survival:golden_sword`. Все 25 имён уже поддержаны загрузчиком. В текущем каталоге этапа 3 существует только деревянная кирка-образец; остальные изображения подготовлены для будущих инструментов, сами предметы и их механика этим обновлением не добавляются.

Атлас блоков и исходные 17 PNG уровнем выше не изменялись. Значки используют тот же кеш для каталога, хотбара, курсора и спрайтов предметов в мире.
