# Voxel Sandbox Rust

3D-воксельная песочница на **Rust + Bevy**. Этот репозиторий — стартовая структура для поэтапной разработки игры, вдохновлённой исследованием, строительством, крафтом, механизмами, боссами, авиацией и драконами.

> **Текущий статус: bootstrap / pre-1.0.** Реализованы минимальное приложение Bevy, открывающее окно, и ядро `game_core`: стабильные ID, координаты, ограниченные секции и общие контракты подсистем. **Это ещё не играбельная версия 1.0.** Ядро не зависит от Bevy; реализации генерации, рендера мира, игрока и сохранений ещё не добавлены.

## Стек

- Rust, edition 2024
- Bevy `=0.20.1` (версия закреплена в workspace manifest)
- Cargo workspace (client + game_core), расширяемый по мере необходимости
- В будущем: `serde`, RON, zstd, meshing, ECS, серверная симуляция

## Быстрый старт

Установить Rust: <https://rustup.rs/>

```bash
cargo run -p voxel-client
```

Для проверки:

```bash
cargo fmt --all -- --check
cargo check --workspace
cargo test --workspace
```

Первый результат — **пустое окно Bevy**. Управление, чанки, блоки, сохранения и крафт ещё не реализованы.

## Версии

- **1.0** — минимальная играбельная песочница: мир, движение, блоки, инвентарь, базовый крафт, сохранения.
- **1.1–1.3** — руды, экипировка, биомы, выживание и мобы.
- **1.4** — мультиплеер.
- **1.5** — механизмы и вращательная энергия.
- **1.6–1.7** — боссы, прогрессия, Нижний мир.
- **1.8** — авиация.
- **1.9** — драконы и кузни.
- **2.0** — расширенный контент, поезда и оптимизация.

См. подробный [план версий](docs/ROADMAP.md), [архитектуру](docs/ARCHITECTURE.md), [параллельные задачи](docs/PARALLEL_WORK.md) и [исходное техническое задание](docs/ORIGINAL_REQUIREMENTS.md).

## Работа в команде / с ИИ

- Новая независимая задача → отдельная ветка `feature/<module>-<task>`.
- Контракты ядра (`game_core`) согласуются перед изменениями.
- Любые функции требуют проверяемых критериев завершения.
- Нет права писать «тесты пройдены», если команды не были запущены.
- Сборка проекта и тесты проверяются перед слиянием.

Лицензия проекта пока не выбрана. До выбора лицензии сторонним участникам не предоставляется автоматическое разрешение на повторное использование исходников.
