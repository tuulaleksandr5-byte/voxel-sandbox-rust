# Пересмотр этапа 1 — Survival с животными и едой

Новое ТЗ от 9 ноября 2026 года просит начать с этапа 1. Подготовлены анализ текущего кода, обновлённый план и примеры RON. Игровой Rust-код, версии зависимостей, исходные PNG и выпущенный Windows-превью этапа 2 не изменены. Животные, еда и атака пока не реализованы.

## Найденные точки расширения

| Система | Сейчас | Расширение по новому ТЗ |
|---|---|---|
| Блоки | `game_core/src/blocks.rs`, 16 стабильных ID | Строковые ID, реестры, свойства добычи, шерсть и новые материалы |
| Инвентарь | `session.rs`, бесконечный hotbar на 9 ID | Предметы/стеки, 27 основных, броня и вторая рука; общие слоты контейнеров |
| Состояния | `GameMode`, Vitals, Mode::Dead/Console уже есть | Сохранить этап 2; добавить общие действия/события ActorId/DamageEvent |
| Мир/стриминг | `World` и `streaming.rs`, секции/меши | Отдельный AnimalStore, устойчивые AnimalId, маркеры первоначального спавна, атомарный перенос между чанками |
| Физика | `interaction.rs::move_player`, ширина 0.6 | Общий move_body с шириной 0.4/0.9, сохранив обёртку игрока |
| Загрузка территории | `World::block` считает отсутствующий чанк AIR | Отдельный loaded-query для AI/спавна; неизвестное пространство недоступно |
| Сохранение | Проверенный JSON schema1/generator1 | Полное хранение животных/предметов/статов и миграция на этапе 9 |

[Основной план](SURVIVAL_V2_PLAN.md) содержит точные параметры четырёх видов, еды, боя, стрижки и яиц. Отдельный [план этой ревизии](superpowers/plans/2026-11-09-v2-survival-animals.md) определяет проверяемые шаги этапа 1. Полное [новое ТЗ](superpowers/specs/2026-11-09-v2-survival-animals.md) сохранено без сокращений; нормализованы только окончания строк. Старое ТЗ и отчёт прошлого этапа 2 остаются историей.

Изменены:

- `README.md`, `docs/ROADMAP.md`, `docs/SURVIVAL_V2_PLAN.md` — девять этапов, текущий статус и зависимости.

Пять обязательных примеров блок/предмет/руда/рецепт/инструмент сохранены. Все примеры — декларации будущих схем, не активный каталог. Единственный действующий файл баланса персонажа остаётся `assets/data/survival.ron`. Все новые файлы целиком и diff изменённых передаются в отдельном patch; новые файлы в нём отмечены `new file mode`.

## Проверка

- Синтаксис всех 10 RON-примеров разобран существующими ron 0.12.3 и serde 1.0.229 через IgnoredAny во временном инструменте вне проекта. Это не типизированная проверка будущих схем; её добавит загрузчик этапа 3.
- Format, check, Clippy с `-D warnings`, полный test и build пройдены. **112 тестов**, 0 ошибок: 51 ядро, 30 рендер, 1 интеграционный, 30 клиент.
- Фактический запуск Linux/Xvfb/Vulkan пройден: меню, форма нового мира, переключатель Survival/Creative, создание мира seed 3, здоровье/голод/хотбар, F3 и команда /gamemode creative. Это smoke-проверка сохранности прежней реализации, не новый тест животных.
- Подтверждены неизменность Rust/Cargo/действующего survival.ron и SHA-256 всех 17 PNG, а также совпадение текста нового spec с присланным после нормализации окончаний строк.

Новых зависимостей нет. `bincode`/`zstd` остаются предложением для этапа 9; A* можно реализовать существующими коллекциями Rust без нового crate.

## Запуск и ручная проверка

```bash
cargo run --locked -p voxel-client
```

Проверить меню, выбор Survival/Creative, создание мира, здоровье/голод/хотбар, F3 и консоль `/gamemode creative`. Это проверка сохранности этапа 2; животных и еду сейчас ожидать не следует. Для новых схем прочитать `examples/README.md` и сравнить численные поля с ТЗ, отдельно от помеченных допущений. Сохранения для проверки вынесены в отдельный временный каталог через VOXEL_SAVE_DIR.

Требования этапа 2 в новом ТЗ не изменились: его реализация сохранена и проверена. Следующий «дальше» разрешает этап 3 — предметы/стеки/дроп/инвентарь/контейнеры. Животные/еда — этап 6, жарка/крафт — 7, XP — 8, полные сохранения — 9.
