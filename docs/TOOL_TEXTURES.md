# Текстуры инструментов из tools.zip

Обновление графики поверх 2.0 Survival, этапа 3. Подключён пользовательский набор из 25 инструментов в трёх размерах и двух общих изображений — всего 77 PNG. Файлы сохранены без изменения байтов в `assets/textures/tools/`; SHA-256 указаны в манифесте этой папки.

Действующий образец деревянной кирки теперь отображает `128x128/wooden_pickaxe.png` вместо процедурной заглушки. Прозрачность, полупрозрачные края и направление рисунка сохранены. PNG не переворачивается, не обрезается и не масштабируется при декодировании; интерфейс отображает его с обычной линейной фильтрацией. Остальные 24 привязки готовы по ID `survival:<имя>` для будущего каталога инструментов. Этап 4, новые инструменты, рецепты и механика экипировки этим обновлением не запускаются.

Новый `apps/client/src/tool_textures.rs` содержит проверяемую загрузку и встроенные оригиналы 128×128. `item_icons.rs` сначала использует предоставленное изображение; для остальных предметов сохраняется прежняя заглушка. Внешний PNG рядом с EXE или в рабочем каталоге можно заменить с последующим перезапуском. Если он повреждён или имеет неверный размер, используется встроенный оригинал с warning. Без папки assets EXE работает со встроенными изображениями.

Новых зависимостей и изменений версий библиотек нет. Каталог предметов, мир и игровой баланс не изменены. Ограничения этапа 3 сохраняются: инвентарь/дроп/сундуки пока живут до закрытия мира, полное хранение относится к этапу 9.

Проверки: прошли 184 теста рабочего пространства в Linux и 183 теста Windows-сборки через Wine, форматирование и Clippy с запретом предупреждений. Linux-клиент и отдельный Windows EXE запущены через Xvfb/Vulkan; значок проверен в каталоге и хотбаре. Windows EXE проверяется без внешней папки assets, чтобы подтвердить работу встроенного PNG. Настоящая Windows-машина этим запуском не проверена.

Добавлены проверка реального кешированного значка против RGBA исходного PNG, соответствия всех 25 ID, полупрозрачности, отказа неверного размера и восстановления при отсутствующем/повреждённом внешнем файле. Для нового значка сначала наблюдалось падение проверки на старой заглушке, затем успешное прохождение после подключения PNG. Проверка SHA-256 подтвердила неизменность всех 77 загруженных PNG и прежних 17 текстур блоков; 25 PNG инструментов и 17 исходных PNG блоков присутствуют в Windows EXE побайтно.
