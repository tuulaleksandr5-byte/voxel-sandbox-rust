# Путь к версиям 1.0–2.0

Текущий статус: **0.1 — рабочий творческий фундамент, pre-1.0**. Проверенные возможности и оставшиеся ограничения перечислены в README и docs/VALIDATION.md.

| Версия | Результат | Критерий готовности |
|---|---|---|
| 1.0 | Творческий мир, персонаж, строительство, инвентарь и сохранения | Можно создать мир, добыть блок, построить дом, перезапустить игру и продолжить |
| 1.1 | Руды и экипировка | Руды по высоте, уровни инструментов, таблицы дропа и броня проверяются тестами |
| 1.2 | Живой мир | Биомы, деревья, пещеры, структуры, вода и погода не ломают детерминизм |
| 1.3 | Выживание и мобы | Здоровье, голод, опыт, базовый бой, нейтральные и враждебные мобы |
| 1.4 | Мультиплеер | 2 игрока синхронно меняют один мир; нагрузочный сценарий на 10 игроков |
| 1.5 | Машины и кинетика | RPM, передача, стресс, прессы, бассейн, миксер, латунь, конвейеры |
| 1.6 | Ранние боссы | Боссы имеют фазы, лут и WorldTierUp без порчи чанков |
| 1.7 | Нижний мир | Измерения, Хелстил, Стена плоти, Адамант |
| 1.8 | Авиация | Гироплан, самолёт, вертолёт, дирижабль и их сохранение |
| 1.9 | Драконы | Огненные, ледяные, молниевые драконы; приручение, кузня, сталь |
| 2.0 | Полная прогрессия | Поздние боссы, звёздный металл, поезда, улучшения контента и стабильности |

## Версия 1.0 — 6 независимых потоков (после согласования контрактов)

1. Мир: блоки, секции, генерация, очереди чанков.
2. Рендер: meshing, видимость, обновление изменённых секций.
3. Игрок: FPS-камера, движение, коллизии, raycast.
4. Предметы: творческий каталог блоков и хотбар; инструменты и рецепты — после 1.0.
5. Сохранения: версии формата, безопасная запись и загрузка.
6. UI и QA: меню, настройки, автоматические тесты, CI.

## Вне 1.0

Боссы, летающая техника, драконы, механические сети, поезда, сложная магия и полноценная сеть. Их контракты учитываются архитектурно, но они не реализуются сейчас.

## Правило релиза

Функциональность считается готовой только после фактического запуска, прохождения тестов и проверки старых сохранений. Работа над новой версией не оправдывает поломку существующих возможностей.
